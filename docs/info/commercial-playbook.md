# Commercial Playbook — The Chaos Engine

> Template system for generating hundreds of funny, high-conversion commercials at scale.
> Originally designed for apps (Base44 mockery / Fixer vs AI Slop).
> Adapted here for **any industry** — local businesses, SaaS, e-commerce, services.

---

## 1. The Roadrunner Formula (Core Philosophy)

Every commercial uses the **same predictable skeleton** with **unpredictable details**.

Why it works:
- Viewers recognize the format → brand recall
- Viewers can't predict the specifics → keep watching
- Guaranteed payoff (destruction / reveal) → satisfying close

Wile E. Coyote formula: you know he's going to fail. You don't know how. That's why you watch.

**Structural requirement:** Every commercial MUST have:
1. **Same hook opener** (recognizable brand beat)
2. **3 randomized middle beats** (slot machine)
3. **Guaranteed destruction / disaster / reveal** (always different)
4. **Sharp CTA** (the hero/brand shows up)

## 3. The 5 Mixing Formats

Every slot variation fits ONE of these 5 framings. Mix across formats for maximum unpredictability.

### Format 1 — Logic Leap
Character uses absurd metaphor to justify absurd action.
- **App example:** "Spare tire on laptop → rolling updates"
- **Plumber example:** "Drilling hole in pipe → extra drainage"
- **HVAC example:** "Fans taped to window → DIY AC unit"
- **Restaurant example:** "Microwave on full for 20 min → sous vide"

### Format 2 — Medical Emergency
Treats the problem like a medical condition requiring fluids/life support.
- **App:** "IV of Mountain Dew into USB port → hydrate the logic"
- **Car:** "IV of vegetable oil into engine → lubrication therapy"
- **Roof:** "Taping Band-Aids on shingles → wound care"

### Format 3 — Safety First
Over-applies safety gear to cover up incompetence.
- **App:** "Life jacket on keyboard → drowning in code"
- **Plumber:** "Floaties on toilet → flood prevention"
- **Electrician:** "Oven mitts to handle wires → insulation"

### Format 4 — Vintage Upgrade
Uses obviously outdated tech to "upgrade" modern gear.
- **App:** "Swatch watch bands on monitor → chrono-sync"
- **Dentist:** "VHS tape instead of X-ray → retro diagnostics"
- **Real estate:** "Polaroid photos for listings → authentic vibes"

### Format 5 — Military Precision
Treats household task like special ops.
- **App:** "Snorkel + goggles → deep sea coding"
- **Landscaper:** "Night vision to mow lawn → tactical turf"
- **Chef:** "Tactical helmet to chop onions → anti-tear ops"

## 6. Characters (Optional Layer)

### THE HERO (THE FIXER)
- Silhouette/suit aesthetic (James Bond + Morpheus)
- Morphs OUT of the screen or solution itself
- Suit texture = the brand's aesthetic (UI elements for app, tool pattern for service)
- Calm, capable, clean motion

### THE VILLAIN (THE PROBLEM)
- For apps: AI Slop — Jabba-meets-Slimer purple blob
- For plumbing: "The Clog" — gross black sludge monster
- For HVAC: "The Drafty" — ghostly wind entity
- For electrical: "The Short" — crackling lightning imp
- For legal: "The Loophole" — a maze of red tape w/ eyes
- Industry-specific — always same villain per brand → recognizable

### CHARACTER IMPLEMENTATION (hyperframes)

Both characters are **static PNG/SVG art** (generated ONCE via Gemini/Nano Banana). GSAP animates them in hyperframes.
- Zero drift (not regenerated per render)
- Consistent across 1000s of videos
- Free to produce

## 7. Episodic Rollout Strategy

### Wave Pattern (per template)
```
Day 1-10    : Base version heavy rotation
Day 8-12    : Introduce variations, still same format
Day 11-15   : Stagger — new template teased inside old template
Day 13-18   : Old + new run in parallel
Day 16+     : New template takes over, old retires
```

### Cross-Template Continuity
- Same hero (Fixer) appears in ALL templates
- Same villain evolves (Slop → Clog → Short → etc.)
- Viewers build parasocial familiarity
- Gamification: "which villain will it be this week?"

### Social Distribution
- Hand off MP4 + captions to existing 13-platform posting tool ($41/mo)
- Native format per platform auto-handled by that tool
- Schedule 3/day per biz if doing posting service

## 10. Slot Machine Combinatorics — Why This Works

One template w/ 15 options per slot = **50,625 unique videos** you can render.

If you have 5 templates × 50,625 = **253,125 unique commercials available.**

At 300 renders/day = **you could run 844 days without repeating a single business's video.**

Template velocity is the ACTUAL bottleneck. Each template unlocks 50k+ renders. Prioritize CRANKING TEMPLATES, not iterating existing ones to perfection.
