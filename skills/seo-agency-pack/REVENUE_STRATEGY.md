## Technical Question: SDK vs API Key

**Critical to find out from Caleb's dashboard:**

| Connection Method | What It Means | Cost Implication |
|------------------|--------------|-----------------|
| API Key (direct) | User needs their own Anthropic API key | User pays per-token on top of group fee |
| SDK (subscription) | Routes through Anthropic subscription | Included in Claude Pro/Team subscription |
| Proxy/Gateway | Caleb's server routes API calls | Caleb absorbs token cost (unlikely at scale) |

**Why this matters:**
- If API key → total cost = $77/mo group + $20-$200/mo API usage = $97-$277/mo
- If subscription → total cost = $77/mo group + $20/mo Claude Pro = $97/mo flat
- If proxy → total cost = $77/mo only (unsustainable for Caleb)

Most likely: **Users bring their own API key or subscription.** The dashboard is the orchestration layer, not the AI provider.

**Find out tomorrow when you get access.** This affects how you pitch the total cost to businesses.
