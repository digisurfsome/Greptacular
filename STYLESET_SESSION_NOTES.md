## 2. The Core Product Concept

### The Problem
Every AI-generated app looks the same. Same rounded corners. Same purple gradients. Same shadcn/tailwind defaults. It's all "AI slop."

### The Solution
**StyleSet** — a design system/style injection layer that gives AI-generated code a distinct visual identity. Pick a style once, it's applied to everything the AI builds.

### The 48 Styles Concept
- A library of ~48 distinct, opinionated design styles
- Each style is a complete visual language (colors, typography, spacing, components, personality)
- Users pick one style and it gets applied to all generated code
- Styles range across aesthetics: brutalist, retro, glassmorphism, minimal, bold, playful, corporate, etc.

### "Set and Forget" UX Flow
1. User picks their style (from the 48 options)
2. Style is applied to everything the AI generates
3. Never think about design consistency again

## 4. The Mascot Universe

### StyleSet Character (Hero)
- **Look**: Superhero whose suit IS one of the 48 styles in silhouette form
- **Details**: Pockets look like little dropdowns, UI elements integrated into the suit design
- **Key trait**: Changes outfit/style each episode (every appearance demos a different style)
- **Vibe**: Clean, sharp, confident, slick
- **Signature move**: Morphs out of screens Matrix-style, deletes slop, morphs back in

### AI Slop Character (Villain)
- **Look**: Jabba the Hutt meets Slimer (Ghostbusters green ghost)
- **Behavior**: Oozes over keyboards leaving a slimy trail
- **Effect**: Every key it touches spawns another identical generic component
- **Vibe**: Blobby, gray/green, generic, gross

### "The Cleanup" Animation Storyboard
1. Laptop on desk. Screen shows generic gray dashboard. Same rounded corners. Same purple gradient.
2. **AI Slop** oozes over the keyboard — half Jabba, half Slimer — leaving a translucent green trail. Every key it touches spawns another identical component.
3. Screen glitches. Crackles.
4. **StyleSet** MORPHS out of the screen — Neo-style liquid metal — wearing a suit that IS one of the 48 styles.
5. One gesture. AI Slop's file gets selected. Delete. Dissolves into a glitchy particle poof.
6. StyleSet backflips back INTO the screen.
7. Screen reforms — now showing something completely different and gorgeous. New style.
8. **"StyleSet and Forget."** End card.
