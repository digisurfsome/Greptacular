# Inbox - The Dump Zone

## What Is This?

This is where you throw everything. Don't organize it. Don't format it. Just dump it in.

## What You Can Drop Here

- Text files with app ideas
- Voice transcript exports
- Bullet point lists
- Stream-of-consciousness rants
- Screenshots descriptions
- Feature requests
- "What if..." brainstorms
- Competitor analysis notes
- Anything else -- the engine will figure it out

## How It Works

1. Drop your files here (any `.txt` or `.md` file)
2. Run `python factory/engine/intake.py`
3. The engine reads everything, analyzes it, and tells you where each piece should go
4. Run with `--auto-mount` to let the engine place things automatically

## Tips

- One idea per file works best, but multi-idea files work too (the engine can split them)
- Name your files whatever you want -- the engine reads the content, not the filename
- Files stay here after processing (they're copied, not moved) so you always have the originals
