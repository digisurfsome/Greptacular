# Stage 07: Computer Use Testing

## What Happens Here

Final validation with real browser testing. Actually use the app like a human would -- click buttons, fill forms, check that things look right.

**Input:** Tested codebase from Stage 06.

**Output:** Verified app that works correctly when a real person uses it.

## What Gets Mounted Here

- Browser test scripts and flows
- Visual verification checklists
- User flow test scenarios
- Accessibility checks
- Cross-browser compatibility notes

## The Prompts

Prompts in this stage guide the AI to:
1. Launch the app in a browser
2. Walk through each user flow (sign up, log in, core features)
3. Verify the UI looks correct (no broken layouts, missing images)
4. Test edge cases (empty states, error states, long text)
5. Check responsive design (mobile, tablet, desktop)
6. Verify accessibility basics (keyboard nav, screen reader)

## When Is This Stage Done?

When someone has actually used the app in a browser and confirmed it works correctly for all major user flows.
