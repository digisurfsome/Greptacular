# Swiss Army Knife Prompt System

## For Claude Code + Supabase + Vite + React + Tailwind

A modular prompt system for building production-quality apps using vibe coding.
Each module is standalone but designed to work together.

## Modules

| # | Module | Use When |
|---|--------|----------|
| 01 | **Scaffold** | Starting any new app from zero |
| 02 | **Auth** | Adding Supabase auth + Google OAuth + roles |
| 03 | **Data Layer** | Creating tables, RLS, and service layer |
| 04 | **UI Kit** | Building reusable components (Modal, Toast, etc.) |
| 05 | **CRUD Flow** | Building List/Detail/Create/Edit for any entity |
| 06 | **Polish** | Date formatting, loading states, error handling |
| 07 | **Style & Theming** | Applying a visual style with dark mode |
| 08 | **Bug Fix Protocol** | Systematically fixing bugs |
| 09 | **Feature Add** | Adding features to an existing app |
| 10 | **Debug Protocol** | Deep diagnosis when something is broken |
| 11 | **Clean Room** | Reverse-engineering an app into your stack |
| 12 | **PRD Generator** | Turning an idea into a structured spec |
| 13 | **Testing Protocol** | Adding tests and verification |

## How to Use

1. Start a new Claude Code session
2. Paste the module prompt (or save as CLAUDE.md in your project)
3. Fill in the [BRACKETS] with your specifics
4. Let Claude Code execute

## Stack

- **AI Coding Tool:** Claude Code (terminal)
- **Database + Auth:** Supabase
- **Frontend:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Hosting:** Vercel / Netlify / any static host

## Origin

Adapted from a production-tested build system by a 15-year software veteran,
translated from Google AI Studio + Gemini + Firestore to Claude Code + Supabase.

## COMPONENT 1: Modal (Base)

**src/components/ui/Modal.tsx**

The base modal that every other modal builds on. Used for forms, confirmations, and any overlay content.

Requirements:
- Dark overlay backdrop that fades in
- Centered white card that scales up on open
- Close button (X) in top-right corner
- Title slot (optional)
- Content slot (children)
- Closes on Escape key
- Closes on backdrop click (optional, default true)
- Focus trap — Tab stays inside the modal
- Prevents body scroll when open
- Responsive: nearly full-screen on mobile, max-w-md on desktop
- Uses Tailwind only, no animation libraries

```typescript
interface ModalProps {
  isOpen: boolean
  onClose: () => void
  title?: string
  children: React.ReactNode
  /** If false, clicking backdrop won't close. Default: true */
  closeOnBackdrop?: boolean
  /** Width class. Default: 'max-w-md' */
  maxWidth?: string
}
```

Implementation details:
- Use a portal (`createPortal`) to render at document body level
- Backdrop: `fixed inset-0 bg-black/50 z-50` with fade-in animation
- Card: `bg-surface-base rounded-xl border border-border-subtle shadow-lg` with scale animation
- Close button: `absolute top-4 right-4` with X icon from Lucide
- Escape key: `useEffect` with `keydown` listener
- Body scroll lock: `document.body.style.overflow = 'hidden'` on mount, restore on unmount
- Mobile: `mx-4 max-h-[90vh] overflow-y-auto`
- Focus first focusable element on open

## COMPONENT 2: ConfirmModal

**src/components/ui/ConfirmModal.tsx**

Built on top of Modal. Used for ALL destructive actions (delete, remove, discard).

**RULE: Every destructive action in the app MUST use this component. No exceptions.**

Requirements:
- Title (e.g., "Delete this item?")
- Description (e.g., "This action cannot be undone.")
- Cancel button (secondary style)
- Confirm button (danger style, with loading state)
- Optional: require typing a word to confirm (for account deletion)

```typescript
interface ConfirmModalProps {
  isOpen: boolean
  onClose: () => void
  onConfirm: () => void | Promise<void>
  title: string
  description: string
  confirmLabel?: string       // Default: "Delete"
  cancelLabel?: string        // Default: "Cancel"
  variant?: 'danger' | 'warning'  // Default: 'danger'
  /** If set, user must type this word to enable the confirm button */
  requireConfirmText?: string
}
```

## COMPONENT 4: Button

**src/components/ui/Button.tsx**

The one button to rule them all. Every button in the app uses this.

Requirements:
- Variants: primary, secondary, danger, ghost
- Sizes: sm, md (default), lg
- Loading state: shows spinner, disables click, shows "Loading..." text
- Disabled state: reduced opacity, no pointer events
- Full-width option
- Icon support (left icon slot)
- Proper focus ring for accessibility
- Active press effect (slight scale down)

```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'danger' | 'ghost'
  size?: 'sm' | 'md' | 'lg'
  loading?: boolean
  fullWidth?: boolean
  icon?: React.ReactNode
}
```

Styling per variant:
- **primary:** `bg-brand hover:bg-brand-dark text-white`
- **secondary:** `bg-surface-muted hover:bg-border-subtle text-text-primary border border-border-subtle`
- **danger:** `bg-red-600 hover:bg-red-700 text-white`
- **ghost:** `bg-transparent hover:bg-surface-muted text-text-secondary`

Sizing:
- **sm:** `px-3 py-1.5 text-sm rounded-md`
- **md:** `px-4 py-2.5 text-sm rounded-lg`
- **lg:** `px-6 py-3 text-base rounded-lg`

## COMPONENT 8: Skeleton

**src/components/ui/Skeleton.tsx**

Animated loading placeholder that matches content shape.

**RULE: Use Skeleton for ALL loading states. Never show "Loading..." text. Never use a full-page spinner for content that has a known shape.**

Requirements:
- Shimmer animation (subtle pulse or sweep)
- Configurable width, height, and border-radius
- Pre-built variants: `SkeletonText`, `SkeletonCard`, `SkeletonAvatar`
- Matches the actual content dimensions so the page doesn't jump when content loads

```typescript
interface SkeletonProps {
  className?: string
  /** Width class (e.g., 'w-full', 'w-48'). Default: 'w-full' */
  width?: string
  /** Height class (e.g., 'h-4', 'h-12'). Default: 'h-4' */
  height?: string
  /** Border radius class. Default: 'rounded-md' */
  rounded?: string
}

// Pre-built composites:
function SkeletonCard(): JSX.Element  // Card-shaped placeholder
function SkeletonText({ lines }: { lines?: number }): JSX.Element  // Paragraph placeholder
function SkeletonAvatar({ size }: { size?: 'sm' | 'md' | 'lg' }): JSX.Element
```

The shimmer animation in CSS:
```css
@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

.animate-shimmer {
  background: linear-gradient(
    90deg,
    var(--color-surface-muted) 25%,
    var(--color-border-subtle) 50%,
    var(--color-surface-muted) 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s ease-in-out infinite;
}
```

Add this to **src/index.css** in the animations section.

## BANNED LIST (ENFORCE STRICTLY)

These are NEVER allowed in any component, page, or feature:

| Banned | Use Instead |
|--------|-------------|
| `alert()` | `showToast({ type: 'info', message: '...' })` |
| `confirm()` | `<ConfirmModal>` |
| `prompt()` | `<Modal>` with a form inside |
| `console.log` for user feedback | `showToast()` |
| "Loading..." text | `<Skeleton>` or `<Spinner>` |
| "No items" plain text | `<EmptyState>` with icon and CTA |
| `window.alert` | Toast |
| Inline `<div className="modal...">` | `<Modal>` component |
| Browser default dialogs | Custom components |
