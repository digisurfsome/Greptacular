# Stage 03: Architecture

## What Happens Here

Design the system. Pick the tech stack, plan the file structure, design the database, map out the APIs.

**Input:** PRD with features, user stories, and requirements.

**Output:** Technical architecture document with tech stack, file tree, database schema, and API design.

## What Gets Mounted Here

- Tech stack decision frameworks
- Architecture patterns for common app types
- Database schema templates
- API design guidelines
- File structure conventions

## The Prompts

Prompts in this stage guide the AI to:
1. Choose the right tech stack based on the requirements
2. Design the file and folder structure
3. Plan the database schema (tables, relationships)
4. Design API endpoints (REST, GraphQL, etc.)
5. Identify third-party services needed
6. Plan for scalability and maintainability

## When Is This Stage Done?

When you have a clear blueprint that shows exactly how the app will be structured, what technologies it uses, and how all the pieces fit together.
