# Stage 06: Testing & QA

## What Happens Here

Write tests. Run them. Lint the code. Type-check it. Make sure everything works.

**Input:** Security-hardened codebase from Stage 05.

**Output:** Fully tested codebase with passing tests, clean lint, and no type errors.

## What Gets Mounted Here

- Testing strategies for the chosen stack
- Test template patterns (unit, integration, e2e)
- Linting and formatting configurations
- Type checking setup guides
- CI/CD pipeline templates

## The Prompts

Prompts in this stage guide the AI to:
1. Write unit tests for all core functions
2. Write integration tests for API endpoints
3. Run the linter and fix all warnings
4. Run the type checker and fix all errors
5. Verify all tests pass
6. Check code coverage

## When Is This Stage Done?

When all tests pass, linting is clean, type checking passes, and you have confidence the code works correctly.
