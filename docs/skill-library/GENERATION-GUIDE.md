# Generation Guide — Step by Step

> Follow this guide to generate every skill in the library.
> Do them in priority order: P1 first, then P2, then P3.
> Each skill takes about 5-10 minutes.

---

## One-Time Setup (Do This Once)

### Step 1: Install Context7

Open your terminal and run:

```bash
npm install -g ctx7
```

If you get a permissions error, try:

```bash
sudo npm install -g ctx7
```

### Step 2: Verify It Works

```bash
npx ctx7 --version
```

You should see a version number. If you get an error, make sure Node.js 20+ is installed.

### Step 3: Make Sure Claude Code Is Installed

```bash
claude --version
```

If this doesn't work, install Claude Code first: https://docs.anthropic.com/en/docs/claude-code

### Step 4: Create Your Working Folders

Create the skill library repo on your machine:

```bash
mkdir -p skill-library/skills/{frameworks,ui,styling,components,auth,database,payments,analytics,email,storage,testing,deployment,mobile,state,realtime,devtools,api-backend,ai-ml}
mkdir -p skill-library/bundles
```

That creates all the category folders you need.

## Generating a Skill (Repeat for Each Skill)

### Step 1: Look Up the Skill

Open `MASTER-SKILL-LIST.md` and find the next skill to generate. Each entry has:
- The skill name (this becomes the filename)
- The category (this tells you which folder to save it in)
- The exact prompt to paste

### Step 2: Run the Generator

Open your terminal and run:

```bash
npx ctx7 skills generate
```

This starts an interactive wizard.

### Step 3: Paste the Prompt

When the wizard asks what skill to generate, **paste the exact prompt from MASTER-SKILL-LIST.md**. Do not retype it or paraphrase it. Copy-paste it exactly.

**Example:** For the Next.js App Router skill, you would paste:

```
Generate a Claude Code skill for Next.js 16 App Router. Cover: server components (default), client components ('use client' directive), file-based routing with app/ directory, layouts and templates, loading and error states, route handlers (app/api/), middleware, server actions ('use server'), parallel and intercepting routes, metadata API for SEO, and image optimization with next/image. App Router patterns ONLY — do NOT include any Pages Router patterns. For use in SaaS applications with Supabase and Stripe integration.
```

### Step 4: Answer Clarifying Questions

The wizard may ask you follow-up questions. Here is how to answer the common ones:

| Question | Answer |
|----------|--------|
| "What version?" | Use the latest stable version (check the master list) |
| "What framework context?" | "For use in production SaaS applications" |
| "Include examples?" | "Yes, minimal but complete code examples for each pattern" |
| "What language?" | Use whatever the library uses (TypeScript for web, Dart for Flutter, Python for FastAPI) |
| "Any specific patterns?" | Say "The prompt already lists the specific patterns I need" |

If the wizard asks something not on this list, give the simplest reasonable answer. Don't overthink it.

### Step 5: Review the Generated Output

Once the skill is generated, compare it against `SKILL-TEMPLATE.md`. Check for:

1. **Header block** -- Does it have all 6 metadata fields? (Library, Version, Generated, Source, Category, Boilerplates)
2. **Overview** -- Is it 2-4 sentences?
3. **Core Patterns** -- Are there at least 4 patterns with code examples?
4. **Common Pitfalls** -- Are there at least 3 specific gotchas?
5. **Integration Notes** -- Does it mention at least 2 companion libraries?
6. **Footer** -- Is the generation info at the bottom?

### Step 6: Fix Any Missing Pieces

If the generated skill is missing a section, add it manually. The most common fixes:

**Missing header block:** Add it yourself using this format:

```markdown
# {Library Name} -- Claude Code Skill

> **Library:** {library-name}
> **Version:** {version}
> **Generated:** {today's date}
> **Source:** Context7 -- live documentation pull
> **Category:** {category from master list}
> **Boilerplates:** {web, mobile, dual, or universal}
```

**Missing footer:** Add this at the very bottom:

```markdown
---

*Generated by Context7 on {today's date}. Patterns reflect {library-name} v{version}. Regenerate if the library ships breaking changes.*
```

**Missing Integration Notes:** Add a section with at least 2 bullet points about how this library works with other libraries in the stack. Look at the master list to see which boilerplates this skill belongs to, and mention the other libraries in those boilerplates.

### Step 7: Save the File

Save the skill to the correct folder using the exact filename from the master list:

```bash
# Example: saving the Next.js App Router skill
cp generated-output.md skill-library/skills/frameworks/next-js-app-router.md
```

Or if you are editing in a text editor, do File > Save As and navigate to the correct folder.

**The filename must be kebab-case and match the master list exactly.**

### Step 8: Update the Version Tracker

Open `skill-library/skill-versions.json` and add or update the entry:

```json
{
  "next-js-app-router": {
    "library": "next",
    "version": "16.2.0",
    "generated": "2026-04-06"
  }
}
```

Use the actual version number from the generated skill's header block.

### Step 9: Check It Off

Go back to `MASTER-SKILL-LIST.md` and mentally note which skill you just finished. (Or keep a separate checklist -- whatever works for you.)

## Quality Check Pass (After All Skills Are Done)

Once you have generated all 60+ skills, do a final quality pass.

### Quick Scan (5 minutes per skill)

For each skill file, open it and check:

1. **Filename matches the master list** -- Is it in the right folder with the right name?
2. **Header block is complete** -- All 6 fields filled in?
3. **No placeholder text** -- Search for `{` in the file. If you find any `{placeholder}` text, replace it.
4. **Code examples have language tags** -- Every code block should start with ` ```tsx ` or ` ```ts ` or ` ```dart ` etc., not just ` ``` `.
5. **No deprecated APIs** -- If you know the library, skim the patterns for obviously outdated stuff.

### Common Problems to Fix

| Problem | Fix |
|---------|-----|
| Code examples use old API | Regenerate just that section using ctx7 |
| Missing Integration Notes section | Add 2-3 bullet points about companion libraries |
| Pitfalls are too vague ("be careful with X") | Rewrite to say exactly what to do instead |
| Skill is too long (over 500 lines) | Trim code examples to essentials; remove verbose explanations |
| Skill is too short (under 50 lines) | Regenerate with a more detailed prompt |

## Batch Generation Tips

When you are grinding through many skills back-to-back:

1. **Do all skills in one category before moving to the next.** This keeps your brain in context. Do all the auth skills, then all the database skills, etc.

2. **Keep the master list open in one window, the terminal in another, and a text editor in the third.** Copy prompt from master list, paste in terminal, review in editor.

3. **Do P1 skills first (25 skills).** These are the most important and cover the core stack. If you get tired after P1, you already have a launchable product.

4. **Take breaks between categories.** Each category takes 30-60 minutes. Don't try to do all 60 in one sitting.

5. **If a generation fails or produces garbage, skip it and come back.** Context7 may have trouble with less popular libraries. Try again later or use a more specific prompt.

## Regenerating a Skill (For Updates)

When a library releases a new version and you need to update a skill:

1. Find the skill in `MASTER-SKILL-LIST.md`
2. Run `npx ctx7 skills generate` with the same prompt
3. The new generation will pull the latest docs automatically
4. Review the new output against the old skill -- make sure nothing important was lost
5. Replace the old file in `skill-library/skills/{category}/{skill-name}.md`
6. Update `skill-versions.json` with the new version and date
7. Commit and push -- subscribers get the update on next `git pull`

## Troubleshooting

### "Command not found: ctx7"

Node.js is not installed or not in your PATH. Install Node.js 20+ from https://nodejs.org

### The wizard asks a question I don't understand

Just type "default" or press Enter. Most questions have sensible defaults.

### The generated skill is completely wrong

Delete it and try again with a more specific prompt. Add details like:
- "Focus on version X.Y specifically"
- "Include TypeScript examples only"
- "For server-side rendering context"

### The generated skill is missing code examples

Regenerate with this added to the end of the prompt: "Include minimal but complete code examples for every pattern."

### I can't find the library in Context7

Some newer or niche libraries may not be indexed yet. In that case:
1. Skip the skill for now
2. Check back in a week -- Context7 indexes new libraries regularly
3. If it is still missing, you can write the skill manually using `SKILL-TEMPLATE.md` as a guide
