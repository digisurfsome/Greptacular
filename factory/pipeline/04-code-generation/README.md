# Stage 04: Code Generation

## What Happens Here

Write the code. Scaffold the project, implement features, get something running.

**Input:** Architecture document with tech stack, file structure, and API design.

**Output:** Working codebase with core features implemented.

## What Gets Mounted Here

- Coding patterns and best practices for the chosen stack
- Scaffold templates
- Implementation order strategies (what to build first)
- Code quality standards and conventions

## The Prompts

Prompts in this stage guide the AI to:
1. Scaffold the project structure
2. Implement core features in priority order
3. Follow the architecture from Stage 03
4. Write clean, maintainable code
5. Add inline comments for complex logic
6. Handle error cases

## When Is This Stage Done?

When the core features work and the app runs. It doesn't need to be perfect -- that's what the next stages are for.
