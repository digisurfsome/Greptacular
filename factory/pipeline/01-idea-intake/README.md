# Stage 01: Idea Intake

## What Happens Here

This is the front door. Raw, unfiltered ideas land here after the engine processes them from the inbox.

**Input:** Voice transcripts, text rants, bullet points, stream-of-consciousness notes, half-baked concepts.

**Output:** Structured idea summaries with a clear core concept, target audience, and key features extracted.

## What Gets Mounted Here

- Brain dumps that need structure
- Voice-to-text transcripts that need cleanup
- Raw feature lists that need context
- "What if we built..." type ideas

## The Prompts

Prompts in this stage guide the AI to:
1. Read the raw input (however messy it is)
2. Extract the core concept -- what is this person actually trying to build?
3. Identify the target user -- who would use this?
4. Pull out concrete features from the noise
5. Flag any ambiguities that need human clarification

## When Is This Stage Done?

When you have a clean, structured summary of the idea that anyone could read and understand what the app does. No jargon, no noise -- just the core concept.
