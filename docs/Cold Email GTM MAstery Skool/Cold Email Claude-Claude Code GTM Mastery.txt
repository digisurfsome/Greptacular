2.2 — Apollo (Lead Search)
Apollo is your lead source. It holds 275M+ contacts with verified company data, job titles, and filters that let you target exactly who you want.
What it does: You define your ICP (industry, title, company size, location), Apollo returns matching contacts with names, emails, companies, and LinkedIn URLs.
Apollo API Call:
POST https://api.apollo.io/api/v1/mixed_people/search
Headers:
  Content-Type: application/json
  X-Api-Key: YOUR_APOLLO_API_KEY


Body:
{
  "person_titles": ["CEO", "Founder", "Head of Marketing"],
  "organization_num_employees_ranges": ["1,50", "51,200"],
  "person_locations": ["United States"],
  "organization_industry_tag_ids": ["construction"],
  "per_page": 50,
  "page": 1
}
Key filters:
person_titles — Job titles to target
organization_num_employees_ranges — Company size brackets
person_locations — Geographic targeting
organization_industry_tag_ids — Industry filters
What you get back: An array of people objects — each with name, email, title, company name, company domain, LinkedIn URL, and company metadata.
Warning
Apollo Basic plan is required. The free plan blocks mixed_people/search— you'll get a 403 error. Don't waste time debugging auth when it's a plan restriction.
Action
Run your first Apollo search. Pull 50 contacts. Save the JSON to a file and inspect the data structure.
2.3 — Blitz OR Prospeo (Email Enrichment)
I personally use Blitz API so that will be what I use in this example
Apollo emails aren't always verified. Blitz runs contacts through multiple verification providers to get you clean, deliverable emails.
Two endpoints you'll use:
Waterfall ICP Search
POST https://app.useblitz.co/api/search/waterfall-icp
// Searches + enriches in one call
// Good for bulk discovery
Email Finder
POST https://app.useblitz.co/v2/enrichment/email
// Requires person_linkedin_url
// Best for targeted enrichment of known contacts
Warning
The cascade gotcha. The cascade field must be an array, and include_title must be an array of strings. This will silently fail if you get it wrong.
WRONG
{
  "cascade": "waterfall",
  "include_title": "CEO"
}
RIGHT
{
  "cascade": ["waterfall"],
  "include_title": ["CEO", "Founder"]
}
Rate limit: 5 requests per second. Build a delay into your enrichment loop or you'll get throttled.
Action
Run 10 Apollo contacts through Blitz. What's your verification rate? Track how many come back with verified emails vs. how many you sent in.


2.4 — Claude API (Script Generation)
This is the differentiator. You're not writing templates with merge fields like {{first_name}}. You're generating actual unique emails per contact — different angle, different hook, different language every time.
Claude API Call
POST https://api.anthropic.com/v1/messages
Headers:
  x-api-key: YOUR_CLAUDE_API_KEY
  anthropic-version: 2023-06-01
  Content-Type: application/json
What to pass in the prompt: Name, title, company, industry, pain points, your offer, and constraints. The more context Claude has, the better the script.
The rules every script must follow:
No signatures or sign-offs
No Subject lines
Under 80-100 words
End with a question
Never start with "I"
No "I hope this finds you well" or similar filler
Pro Tip
Run 5 concurrent workers. Sequential = slow. Parallel = 200 scripts in minutes instead of hours. Use Promise.all() with batches of 5.

2.5 — SmartLead (Campaign Management)
SmartLead handles everything after you generate scripts: account rotation, email warmup, send throttling, and reply detection. You push leads in, it sends them out across multiple mailboxes.
What it handles:
Account rotation across multiple sending mailboxes
Email warmup to build sender reputation
Send throttling to stay under provider limits
Reply detection and lead status tracking
The key: Use the custom_script field when pushing leads. In your SmartLead campaign template, use the {{custom_script}} variable in the email body. This lets every email be unique.
Deduplication is critical.
 Before pushing new leads, check what's already in the campaign:


// 1. GET existing leads from SmartLead campaign

// 3. Filter out duplicates

3.1 — Pipeline Architecture
The pipeline is 7 steps, run in sequence. Each step takes the output of the previous one and transforms it.
1 Apollo Search — Query your ICP filters, pull raw contacts with names, titles, companies, and LinkedIn URLs.
2 Blitz Enrichment— Run contacts through Blitz to get verified email addresses. Discard anything that doesn't verify.
3 Deduplication — Check against SmartLead and your Supabase CRM. Never email the same person twice from the same campaign.
4 Claude Script Generation — Generate a unique, personalized email for every contact. No templates — fully written scripts.
5 SmartLead Push — Push leads with their custom scripts into the campaign. SmartLead handles rotation and sending.
6 Telegram Notify — Send a summary notification: how many leads, verification rate, campaign name.
7 CSV Log — Append a row to your daily log with date, client, count, campaign ID, and verification rate.
Pro Tip
Save incrementally. Every 10 rows. If your script crashes at row 150, you don't lose 149 contacts. Write to disk frequently — memory is volatile, files are not.

Deduplication — The Step Everyone Skips
Why You'll Burn Campaigns Without This
Before adding leads to any campaign, check SmartLead for existing emails. Sending to someone who's already in the campaign tanks your deliverability and makes you look amateur.
// Pull all existing leads from the campaign
const response = await fetch(
  `https://server.smartlead.ai/api/v1/campaigns/${campaignId}/leads?api_key=${key}&limit=10000`
);
const existing = await response.json();

// Build a Set of existing emails
const existingEmails = new Set(existing.map(l => l.email.toLowerCase()));

// Filter out duplicates
const newLeads = contacts.filter(
  c => !existingEmails.has(c.email.toLowerCase())
);

console.log(`${contacts.length} total → ${newLeads.length} new (filtered ${contacts.length - newLeads.length} dupes)`);
