# Commercial Video Templates — Social Media Ad System

> These templates form the content engine for the Video Variator app.
> Each template is a standalone commercial format with swappable variable slots.
> The system is designed to be automated via JSON + Veo 3 text-to-video generation.

---

## How The System Works

Every commercial is built from a **Base Scene** + **3 Variable Slots** + **Destruction Ending**.

```
[BASE SCENE - same every time]
      ↓
[VARIABLE A: Hardware Hack]
      ↓
[VARIABLE B: Absurd Rationale]  ← these 3 shuffle independently
      ↓
[VARIABLE C: Dialogue Format]
      ↓
[DESTRUCTION ENDING]
      ↓
[PRODUCT REVEAL / CTA]
```

People recognize the Base Scene → they don't know which 3 mix-ups they'll get → open loop forces them to watch to close it.
15 options per slot = 3,375 unique combinations from one filming session.

## TEMPLATE 2: The Graduation

**The origin story. Guy throws away the Toys R Us laptop and tries to "upgrade."**

### Concept
Guy is graduating from Base44 (the toy laptop era) to "real" vibe coding. He's proud. He doesn't realize he's just upgrading from one level of clueless to the next. Until the Normie Flows intervention.

### Scene Breakdown

| Beat | Visual | Audio/Dialogue |
|------|--------|----------------|
| Opening | Close-up of "VIBE CODING" labeled toy laptop in Toys R Us packaging | Triumphant music |
| The Throw | Guy theatrically tosses it in trash | "I am DONE with my Toys R Us era." |
| The Upgrade | He opens a real MacBook, visibly proud | "Time to make some REAL AI Slop." |
| The Reality | He immediately starts bolting training wheels to the new laptop | Same energy. Same problem. |
| The Crack | Screen spiders from over-tightened bolt | "Perfect. Now we're cooking." |
| The Intervention | Glowing blue light hits his face. He looks up at the Normie Flows dashboard | VO: "You graduated the laptop. Not the process." |
| CTA | Fast-cut product demo | "Graduate the process. Normie Flows." |

### Key Dialogue Lines
- "I'm graduating from my Toys R Us laptop." (proudly)
- "Can't wait. I'll be making AI Slop in no time." (pumped up)
- "I was told this would be easy." (3 weeks later, still bolting things)
- "Hey... would you like to learn the real way to do this?" (intervention moment)

### Variations (Variable Slot: The "Upgrade" Mistake)
Instead of training wheels, the graduation mistake can be:
- Trying to bolt the old toy laptop's parts onto the new one
- Printing out Base44 screenshots and taping them to the screen as "reference"
- Wearing the Toys R Us receipt around his neck like a credential
- Calling his mom to celebrate "I'm a real coder now" while screen is cracked

## TEMPLATE 3: The Hero vs. AI Slop (Style Set)

**The brand superhero format. Product becomes a character.**

### Concept
The Style Set renderer is on screen. The AI Slop character (Jabba the Hutt x Ghostbusters Slimer, purple/glitchy) is corrupting everything. The Fixer morphs out of the app like Morpheus from The Matrix and whoops the Slop's ass. Every punch changes the UI style on screen — which changes The Fixer's suit in real time.

### Characters

**The Fixer (Hero)**
- Silhouette: Sleek, James Bond suit
- The suit is MADE of the app style — pockets look like UI cards, buttons on jacket are actual style buttons, dropdowns visible in lapel
- Morphs out of the 2D screen like liquid mercury
- As styles toggle during the fight, his suit shifts with them (Neomorphic → Cyberpunk → Minimalist)
- At the end: whoops the Slop's ass, morphs back into the screen like nothing happened

**AI Slop (Villain)**
- Visual: Translucent purple gelatinous mass
- Jabba the Hutt body, Ghostbusters Slimer energy
- Leaves trail of purple glow, glitchy artifacts, low-res corrupted UI everywhere
- Drips onto keyboard changing the keys to look glitchy and corrupted

### Scene Breakdown

| Beat | Visual |
|------|--------|
| Setup | Laptop on desk, Style Set app open, clean UI visible |
| Villain Enters | AI Slop oozes across the keyboard, corrupting keys to purple glow |
| Hero Morph | The Fixer liquefies out of the screen — suit texture matches current app style |
| Fight | They fight across the keyboard — each impact triggers a style shift on screen |
| Style Cascade | Every punch: Neomorphism → Brutalism → Glassmorphism → Cyberpunk (Fixer's suit morphs with each) |
| Kill Shot | Fixer lands the final blow — Slop splatters and dissolves into clean UI |
| Return | Fixer morphs back into the screen like nothing happened |
| Product Demo | Hands-on toggle through Style Set — the fidget spinner moment |
| CTA | "Set your UI and forget it." |

### The Suit Detail (Key Visual)
- Suit pockets = glass-morphism cards
- Buttons on jacket = actual neon brutalist toggle buttons
- Collar = gradient bar from current color scheme
- When style changes: entire suit texture shifts in 0.3 seconds

## TEMPLATE 5: The Open Loop Destruction Engine (Meta-Template)

**The system template. Describes HOW all templates above get assembled.**

### The Prediction Problem (Why This Works)
If the audience can predict the punchline, they mentally skip the ad.
Solution: Shuffle 3 variables from different pools — they can't predict which 3 combine.

```
VARIABLE A (Hardware Hack) × VARIABLE B (Rationale) × VARIABLE C (Dialogue Format)
    15 options           ×       15 options          ×       5 options
= 1,125 unique mid-sections

× 15 Destruction modes = 16,875 unique combinations
```

### The Engagement Loop

```
Episode 1: Training Wheels + "Rolling Updates" + Logic Leap + Tire through drywall
           → Audience learns: "Oh, it ends with destruction"

Episode 5: IV Drip + "Hydrating logic" + Medical Emergency + Laptop explodes
           → Audience thinks: "I knew it'd get destroyed, but NOT like that"

Episode 10: Swatch Bands + "Chrono-fix" + Vintage Upgrade + Turns to dust
           → Audience actively watching for the destruction type: "What's it gonna be?"

Episode 15+: They're WAITING FOR IT. Open loop every time. Closed only on watch.
```

### The Stagger Strategy (Audience Transfer)
```
Episodes 1-10:  "Training Wheels" series runs
Episodes 8-12:  "Life Jacket" series starts — character in Life Jacket ad 
                is watching Training Wheels ad on his cracked screen (crossover)
Episodes 11-15: Run both series side by side (dual ad sets in retargeting)
Episodes 13+:   Life Jacket series carries full audience
                New series starts peeking in at episode 12-13
```

### The Platform Matrix (7 Platforms, Native Format)
| Platform | Format | Duration | Caption Style |
|----------|--------|----------|---------------|
| TikTok | Vertical 9:16 | 15-30s | Casual, hashtag heavy |
| Instagram Reels | Vertical 9:16 | 15-30s | Visual-first, shorter caption |
| YouTube Shorts | Vertical 9:16 | 60s max | Hook in first 3 seconds |
| Facebook | Square 1:1 or 9:16 | 15-60s | Slightly more copy, CTA button |
| X (Twitter) | 16:9 or 1:1 | 15-30s | Punchy, text-heavy caption |
| LinkedIn | 1:1 or 16:9 | 30-60s | Professional adjacent humor |
| Pinterest | Vertical 2:3 | Static or 15s | More descriptive, SEO keywords |

## Veo 3 Prompt Template (Universal)

Use this structure for every scene generation:

```
[CHARACTER DESCRIPTION — verbatim, consistent across all scenes]
[SETTING — lighting, camera, lens, fps]
[ACTION — specific motion, what changes, what reacts]
[AUDIO — sync points, sound design notes]
[STYLE — cinematic reference, color grading]
[NEGATIVE PROMPTS — what to avoid]
```

**Character Consistency Rule:** The "guy" character description must be pasted verbatim into every scene prompt. Do not paraphrase. This prevents visual drift between episodes.
