# Mounted - Processed Ideas

## What Is This?

This directory holds processed and organized ideas after the intake engine has analyzed and sorted them. Think of it as the archive -- a record of every idea that's been through the system.

## What's In Here

After the engine processes your inbox, it creates summaries here showing:
- The original idea (cleaned up)
- Which pipeline stage(s) it was mounted to
- Any merges or combinations with existing ideas
- The engine's analysis and reasoning

## You Shouldn't Need to Touch This

This folder is managed by the engine. It's here for reference so you can see what's been processed and where things ended up.
